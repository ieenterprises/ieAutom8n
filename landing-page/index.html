Frequently Asked Questions

What makes ieAutom8n different from generic automation tools? ▼

ieAutom8n combines intuitive drag-and-drop workflow building with full code flexibility (JavaScript/Python) and native autonomous AI agents. Unlike rigid platforms, you have full ownership of your data with dedicated PostgreSQL persistence.

Where is my data stored and is it secure? ▼

Your data is stored in your dedicated PostgreSQL database with encrypted credentials. ieAutom8n uses 256-bit encryption for all stored API tokens and environment secrets.

Can users reset their password if they forget it? ▼

Yes! With automated SMTP email enabled, users can click "Forgot password?" on the login screen to receive a secure password reset link directly to their inbox. Admins can also reset passwords directly via the admin console.
